<task type="auto">
  <name>更新 UI 结构与样式</name>
  <files>popup.html, popup.css</files>
  <action>
    在 popup.html 的 options-section 之前添加一个新的 style-section。
    1. 添加字体大小选择：使用 number input 或 select，范围 12px - 24px，步长 1，默认 16px。
    2. 添加页边距选择：使用 select，选项包括“窄 (5mm)”、“标准 (15mm)”、“宽 (25mm)”。
    3. 在 popup.css 中为新部分添加样式，确保与现有 UI 风格统一。
  </action>
  <verify>
    打开扩展 Popup，可以看到新增的“字体大小”和“页边距”控件，布局整齐。
  </verify>

  </done>
</task>

<task type="auto">
  <name>实现配置持久化与逻辑同步</name>
  <files>popup.js</files>
  <action>
    1. 在 DOMContentLoaded 时，从 chrome.storage.local 加载已保存的配置（fontSize, margin）。
    2. 为新添加的控件绑定 change 事件，当值改变时自动保存到 chrome.storage.local (per D-07)。
    3. 修改 getExportConfig 函数，将 fontSize 和 margin 包含在返回的配置对象中。
    4. 确保矢量 PDF (chrome.scripting) 和图片 PDF (sendMessage) 都能接收到这些新参数。
  </action>
  <verify>
    1. 修改字体大小或边距后，重新打开 Popup，设置应保持不变。
    2. 在控制台中打印 getExportConfig() 的结果，确认包含正确的 fontSize 和 margin。
  </verify>
  <done>
    配置已持久化，且能正确传递给导出流程。
  </done>
</task>
